# Security Policy

## Supported versions

This package is pre-1.0 and under active development. Only the latest
published version on pub.dev receives fixes.

## Reporting a vulnerability

Please report security issues privately via
[GitHub Security Advisories](../../security/advisories/new) rather than a
public issue. Include steps to reproduce and the affected version.

We'll acknowledge reports as soon as possible and follow up with a fix or
mitigation timeline.
